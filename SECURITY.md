# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it through GitHub's private vulnerability reporting:

**https://github.com/deploypulseio/react-native-code-push/security/advisories/new**

You can also email **security@deploypulse.io** if you would rather not use GitHub.

Please do not open a public issue for security vulnerabilities.

This package is a fork of [react-native-code-push](https://github.com/codemagic-ci-cd/react-native-code-push). If the
issue is in upstream code rather than in the DeployPulse changes, we will coordinate the report with the upstream
maintainers.
